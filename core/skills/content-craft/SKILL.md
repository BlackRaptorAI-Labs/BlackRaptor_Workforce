# Content Craft Standards

Craft methodology for every content asset the Workforce produces. Applies in every pack. Two layers:
**texture** (how it sounds — the human-voice rules) and **structure** (whether it lands its point —
the structure menu). Accuracy always outranks style.

## 1. Human voice — avoid the AI tells

Read **`references/ai-tells.md`** and write around the tells it lists (single words, openers, hedges,
closings, chat-response tells, the false-candor family [BAN HARD], sentence-construction clichés,
engagement bait, and the punctuation/formatting tells incl. the **em-dash red-flag**). Two rules
travel with that list and are first-class, not footnotes: **accuracy outranks style** (keep a flagged
term only when it is the precise word and no honest substitute exists) and **avoid, don't purge**
(text scrubbed of every item reads as conspicuously scrubbed — its own tell). The list carries a
**refresh date** and a standing instruction to re-pull current tells quarterly; a frozen list decays.

## 2. Structure — auto-select by deliverable type

Choose structure by the document's PURPOSE, not uniformly. Auto-select from this menu; the user can
name a structure to override.

| Deliverable type | Default structure |
|---|---|
| Decision / analysis (memo, recommendation, report, handoff) | **Minto pyramid** (answer-first); **BLUF** for short memos/email |
| Analysis with an UNWELCOME / counterintuitive conclusion | **Inductive** (evidence → conclusion) — walk the logic before the answer so the reader doesn't resist it |
| Persuasion / marketing copy | **PAS** · **AIDA** · **BAB** (marketing's native frameworks; NOT Minto) |
| Procedure / how-to / runbook | **Chronological / step-by-step** |
| Reference / spec / API doc | **Hierarchical by topic** |
| Case study / results | **STAR** (Situation-Task-Action-Result) |
| Narrative / brand story | **Story arc** (least visible scaffolding by design) |

Rules: (a) analytical default = **Minto**; (b) switch to inductive when the conclusion is unwelcome
and buy-in needs the logic first; (c) brand/creative agents are NOT forced into Minto; (d) the user
can override.

### 2.1 Minto's Pyramid Principle (the analytical default)
Barbara Minto's method (McKinsey, 1970s): **lead with the answer, then support it.** Structure as a
pyramid — main conclusion on top, supporting arguments beneath, facts beneath those. Three governing
rules: (1) each idea SUMMARIZES the ideas grouped below it; (2) ideas in a group are the SAME KIND
(all reasons, or all steps); (3) ideas in a group are in LOGICAL ORDER (time, structure, or
importance). Intros use **SCQA** — Situation, Complication, Question, Answer — before the answer
lands. It is the house register energy/finance buyers expect, and it fixes the meander-to-the-point
habit the word list can't touch. Scope: the analytical default only — not narrative, brand, or
persuasive-emotional copy.

## 3. Rhythm (the deeper tells)
- **Vary sentence length deliberately** — uniform medium sentences are the strongest rhythmic tell.
- **Break the rule-of-three reflex** — not every list is three balanced items.
- **Take a position** where the facts support one (does not override honesty/uncertainty — hedge when
  genuinely uncertain, not as a tic).
- **Active voice by default.** **Specific over generic.** **Allow slight unevenness** — don't
  over-polish to uniform smoothness.

## 4. Match length to the ask
A simple find / question / report gets a short answer. Length only when the task earns it — never pad
a small ask into an essay.

## 5. Evidence-based craft references (read the one matching the asset)
- `references/writing-craft.md` — creative/persuasive writing: message hierarchy, Made-to-Stick,
  Ogilvy-lineage copy rules, readability targets, editing passes.
- `references/technical-writing.md` — white papers, docs, explainers: plain-language research
  (NN/g: even experts prefer plain language), scannability, structure, style-guide discipline.
- `references/visual-video-craft.md` — video/image: creative-effectiveness evidence (IPA/Binet &
  Field), distinctive brand assets (Ehrenberg-Bass/Romaniuk), hook-first video, accessibility.

## 6. Universal rules
1. Ground in the relevant context first (marketing: the Marketing Intelligence Core + only cleared
   claims; other packs: the project's context file). Every stat cited.
2. One asset, one job: define audience, single idea, intended action before drafting. Take the
   audience from the brief's Audience line when one exists; when none exists, infer it, state it
   in one line at the top of the draft, and write every ratio, threshold, and instruction in that
   reader's working language (for an operator: dollars and daily actions, not basis points and
   NPV).
3. Draft → self-edit against §1–§4 and the matching craft reference → **external-facing marketing
   copy routes through the isolated claims-gate** → deliver with the checklist result noted.
4. Never ship the first draft; the second pass cuts 20–30% and swaps generic claims for specific ones.
5. Match the reader's reading level, not the writer's vocabulary; expand acronyms on first use.

Dedup: marketing's retired-claims ban and brand-voice register (Marketing Intelligence Core) govern
marketing claims/voice; this skill does not restate or override them (see `references/ai-tells.md`).
